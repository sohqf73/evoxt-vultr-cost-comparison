## Vultr 的账单里，哪部分钱是长期用户白花的

先把价格口径说清楚，因为网上流传的数字对不上。Vultr 官网常见的入门口径是 512MB 款 $3.50/月、1GB 款 $6/月、2GB 款 $12/月；也有对比文章把 1GB 写成 $5/月、把 512MB 写成 $2.50/月。差 1 美元看着不多，年化就是 12 美元，下单前建议自己在价格页点一遍确认。

无论按哪个口径，长期挂机的人都会撞上四笔额外支出。

**按小时计费只在短期有用。** 开一台机器跑 6 小时然后销毁，按小时扣费确实比包月划算，这是 Vultr 最适合的场景。但一台跑了 12 个月没关过的机器，按小时计费和月付没有任何区别，你并没有因为“按小时”省下钱，只是失去了年付折扣这个选项。Vultr 本身不提供年付折扣，月付多少就是多少，第二年也一样。

**带宽超额按 $0.01/GB 计。** 换算下来约 $10/TB。普通网站用不到，但拿来做下载节点、图床、备份中转、代理，流量很容易冲到套餐额度之外，账单会以几美元为单位往上加，而且加得没有明显感知。

**DDoS 防护是付费附加项，$10/月/受保护 IP。** 不是所有套餐默认带，需要单独买。一台 $6/月的机器加一份 DDoS 防护，月成本立刻变成 $16。

**2GB 内存是个价格台阶。** 想要 2GB 以上内存，通常要到 $10–$12/月这一档。对只想跑一个 WordPress 加 MySQL 的人来说，这个价格里包含的全球机房、API、Kubernetes 集成、对象存储，大部分用不上。

还有两个容易被忽略的点：托管数据库只覆盖 MySQL 和 PostgreSQL，没有 Kafka、MongoDB、Redis，需要这些得自己装或换别家；公司总部在美国新泽西，受 CLOUD Act 约束，欧洲业务如果在意数据司法管辖，这是绕不过去的一条。

Vultr 的长处也是真的：30 多个区域/数据中心，全球部署能力在非 hyperscaler 里排得上号；High Frequency 实例跑 3+ GHz，单核性能适合游戏服和实时 API；裸金属 $120/月起、GPU 从 $1.67/GPU-hour 起；VKE 控制面免费。这些能力短期替代不了。

## 换到 Evoxt 之前，这四件事得先接受

**没有按小时计费。** 这是最硬的一条。机器一开就是按月计，跑两天删掉也按整月算。CI/CD 的临时 runner、面试演示环境、给别人看的短期 demo，这些场景用 Evoxt 是浪费。判断方法很简单：如果你过去三个月在 Vultr 上开过 5 台以上“用完就删”的机器，别换。

**没有 DDoS 防护。** 官方功能表里这项标的是不支持。做游戏服、公开 API、容易被盯上的站点，前面必须套 Cloudflare 或类似的防护层。Vultr 那边至少能花 $10/月买到，Evoxt 是买不到，只能自己在架构上解决。OVHcloud 这类默认包含 DDoS 清洗的服务商在这种场景更合适。

**机房集中在美、欧、亚三块。** 官方价格页列出的区域是美国、英国、加拿大、德国、波兰、荷兰、日本东京、马来西亚、澳大利亚。要在南美、中东、非洲落地，Vultr 的 30 多个区域仍然是更实际的选择。

**退款条款没有公开写在价格页上。** 官网的价格页和购买页都没有列出明确的退款期限或退款条件，这一点和按月付、随时销毁的 Vultr 完全不同。下单前建议先开工单问清楚，或者先用最小档 VM-0.5（$2.99/月）跑两周，确认机房的线路和磁盘表现合适，再决定要不要上大配置或长周期预付。

## 其他几个方向，只给信息

**RackNerd。** 主打低价年付锁价，黑五促销口径里 1GB 款 $10.60/年、2.5GB 款 $18.66/年、4GB 款 $29.98/年，KVM、1Gbps 端口、RAID-10 SSD、SolusVM 面板、1 个独立 IPv4。续费按宣传是锁价不涨。限制同样明确：官方条款不提供退款，激活后款项不退；没有原生 API 编排能力，控制面板是 SolusVM，只能手动操作，做不了基础设施即代码。它的常规月付套餐价格表在流传的版本里前后关系不自洽，看的时候以官网结算页为准。数据中心数量在不同来源里从 11 个到 21 个都有，别当固定数字记。

**DediRock。** 机房在洛杉矶和纽约，KVM、完整 root、1 个独立 IPv4、1Gbps 端口，走的是比 RackNerd 更低的年付路线。需要注意的是它的促销价格表内部存在明显矛盾，同一页面上 2GB 的报价低于 1GB，不同配置之间的价格关系说不通，这类表格不能当作稳定报价使用。第三方评测里提到的磁盘顺序读取超过 3GB/s、洛杉矶 iperf 约 900Mbps 这组数据，对应的是更早的一次促销机型，不能直接套到当前在售配置上。想买就先小额试一台。

**Hetzner。** 欧洲业务的首选方向。CX22 入门 €3.29/月，同价位内存比 Vultr 多；5 个数据中心园区分布在德国、芬兰、美国、新加坡；德国总部，不受 CLOUD Act 约束。短板是没有 GPU，也没有托管数据库。

**OVHcloud。** B2-7 给到 2 vCPU / 7GB 内存 / 50GB 存储 / 不限流量，$27.129/月；DDoS 防护默认包含，不用另买；欧洲机房数量多。做大带宽流媒体、或者被打怕了的站点，这个组合比 Vultr 加购 DDoS 更划算。

**DigitalOcean。** 13 个区域，入门 $4/月 512MB。真正的差异在托管服务：PostgreSQL、MySQL、Redis、MongoDB、Kafka、Valkey、OpenSearch 全都有。如果你的架构依赖这些托管组件，Vultr 和 Evoxt 都不该在候选名单里。

**Linode。** 11 个区域，入门 $5/月 Nanode，没有传统裸金属。定位和 DigitalOcean 接近，规模小一些。

## 下单前最后确认三件事

第一，确认机房里有没有你目标用户最近的那个。Evoxt 的日本东京和马来西亚节点对亚太访问友好，但具体线路表现随时段和运营商变化，Vultr 的亚太节点也一样存在绕路情况，别信任何“固定延迟数字”，开最小档实测两三天最靠谱。

第二，确认计费周期。Evoxt 支持月付到 3 年预付，但官方价格页没有标注年付折扣，预付 3 年不会自动便宜，结算页显示多少就是多少。第一次买建议月付，跑顺了再考虑拉长周期。

第三，确认退款规则。Evoxt 官方价格页与购买页没有列出退款条款，这和 Vultr 按月付、随时销毁的模型不一样。不确定就先买 VM-0.5 试水，$2.99 的试错成本比买错一年低得多。

一句话收尾：机器长期开着、单核性能敏感、预算压在每年 $60–$120，Evoxt 的 VM-0.75 到 VM-2 这几档是当前比较实在的落点；机器开开关关、要全球铺点、要按小时结账，Vultr 那部分钱花得不冤。
